# 日々の予定 — React Native版

Expo SDK 54 / React Native 0.81 / React 19。iPhone向けの日本語アプリです。白背景・薄いオレンジ、月間カレンダー、予定の追加・編集・削除、4色、毎日・毎週・毎月・毎年の繰り返し、やることリストを実装しています。旧ウェブ版は `../schedule` に残しています。

## 開発

Node.js 20.19.4以上を使用します。

```sh
cd /workspace/raitenn/schedule-native
npm ci
npx expo start --lan
```

iPhoneと開発PCを同じネットワークに接続し、SDK 54に対応するExpo GoでQRコードを読み取ってください。クラウド環境のlocalhostにはiPhoneから直接アクセスできません。この場合はソースをローカルPCで起動するか、Expoのトンネル接続を別途設定します。最新のExpo GoがSDK 54を受け付けない場合は、対応する開発ビルドが必要です。

MacとXcodeがある場合は `npx expo run:ios --device` で実機向け開発ビルドを作成できます。署名設定が必要です。TestFlightやストア配布にはApple Developer登録・署名と別途ビルド作業が必要です。本作業ではAppleへの公開・実機へのインストールは行いません。

```sh
npm test
npx expo install --check
npx expo export --platform ios
```

`expo export`はJavaScriptバンドルの検証であり、署名済みiOSアプリのビルドや実機試験ではありません。

## 保存・移行

AsyncStorageに端末内保存します。ブラウザーのlocalStorageを自動では読み込めません。旧ウェブ版で「バックアップ保存」し、iPhoneのファイルアプリにJSONを保存して、ネイティブ版の「バックアップ読込」から移行します。同じJSON形式・保存キーを使用します。アプリ削除でデータは失われるため、「バックアップ保存」からファイルに保存してください。

## ローカル通知

「通知を設定」で許可すると、OSに日時指定で予約します。アプリを閉じていても予約済み通知の配信対象になります。通知の実際の表示はiOSの権限・集中モード・端末設定に依存します。

- iOSの保留通知件数制限に余裕を持たせ、全予定で直近60件まで予約。
- 最大5年先までの候補から選び、起動・フォアグラウンド復帰・予定編集時に再予約します。長期間アプリを開かないと予約が尽きます。
- 終日予定・やることは通知対象外。
- 毎月31日や毎年2月29日など存在しない日付はスキップ。繰り返しの編集・削除は全回に反映。
- 端末のタイムゾーン変更後はアプリを開き、再予約してください。
- iOS実機での配信確認は別途必要です。

サーバー、アカウント、外部への予定データ送信はありません。
